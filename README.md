# Corporate Careers Portal

A beginner-friendly responsive corporate careers website developed using HTML5 and CSS3.

## Features

- Responsive Design
- Navigation Bar
- Hero Section
- Services Section
- Career Section
- Cards Layout
- Footer Section

## Technologies Used

- HTML5
- CSS3

## How to Run

1. Download the project files
2. Open `index.html` in your browser

## GitHub Pages Deployment

Go to:

Settings → Pages

Then select:

- Source → Deploy from branch
- Branch → main
- Folder → /root

Save the settings and wait for deployment.
